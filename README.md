# 🟩🟨⬜ Clone do Termo (Meu Primeiro Projeto Web)

Este é um clone do famoso jogo **Termo** (Wordle), desenvolvido inteiramente com **HTML, CSS e JavaScript**. 

Este repositório tem um valor muito especial para o meu portfólio: ele marca o meu **primeiro contato** prático com o desenvolvimento Front-End! Ele foi construído como projeto prático durante o "Curso Front-End Essentials", oferecido aos alunos da Universidade de São Paulo em 2025.

## 🚀 Funcionalidades

O jogo simula a mecânica clássica do Termo, incluindo:
* **Lógica de Tentativas:** O jogador tem 6 chances para adivinhar a palavra de 5 letras.
* **Feedback Visual de Cores:**
  * 🟩 **Verde:** A letra está na palavra e na posição correta.
  * 🟨 **Laranja:** A letra está na palavra, mas na posição errada.
  * ⬜ **Cinza:** A letra não pertence à palavra.
* **Teclado Híbrido:** É possível jogar clicando no teclado virtual gerado na tela ou utilizando o botão `Enter` do teclado físico.
* **Alertas Dinâmicos:** O jogo identifica em qual tentativa o usuário ganhou e exibe uma mensagem comemorativa específica (ex: "DE PRIMEIRA!", "QUASE!").

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do grid de inputs e dos botões.
* **CSS3:** Estilização das caixas, aplicação das cores de feedback e organização do layout utilizando Flexbox.
* **JavaScript (Vanilla):** Lógica central do jogo, manipulação do DOM (`querySelectorAll`, `style.backgroundColor`) e escuta de eventos (`addEventListener`).

## 🎓 Contexto e Certificação

Este projeto foi desenvolvido ao longo de uma oficina de 3 aulas, totalizando **10 horas de curso**, promovida pelo **PET-SI (Programa de Educação Tutorial de Sistemas de Informação) da EACH-USP**, finalizado em agosto de 2025.

Foi o pontapé inicial perfeito para entender como estruturação, estilo e interatividade trabalham juntos no navegador!

## 🕹️ Como executar o projeto

Como o projeto foi feito puramente com tecnologias nativas da web (Vanilla), não é necessária nenhuma instalação de pacotes ou servidores complexos.

1. Baixe os arquivos deste repositório.
2. Dê um duplo clique no arquivo `.html` principal.
3. O jogo abrirá automaticamente no seu navegador padrão e já estará pronto para jogar!
